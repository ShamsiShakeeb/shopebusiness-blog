How it is generated

EasyPost returns a tracking code when a shipment is bought (EasyPost Shipments API) and supports tracker objects for scan history (EasyPost Trackers API). The Worker sends the tracking URL back to Shop-E-Business, signed with your shop secret.

Extending notifications

Developers can extend the Worker to push tracking updates elsewhere; see Cloudflare Workers docs and the Expose API and Cloudflare Worker guide.
