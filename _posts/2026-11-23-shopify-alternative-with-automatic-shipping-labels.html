Short answer: A Shopify alternative with automatic shipping labels is Shop-E-Business Tier-2 ($18/year). When a Stripe order is paid, the store's Cloudflare Worker uses your EasyPost API key to create a shipment, buy the cheapest rate that succeeds and save the tracking code to the order, with no separate shipping app.

How the automatic label flow works

  1. The buyer pays through Stripe Checkout; money goes to your own Stripe account.
  2. Stripe sends a checkout.session.completed webhook.
  3. The Cloudflare Worker calls EasyPost with your ship-from address and parcel size.
  4. EasyPost returns rates; the Worker buys the cheapest rate that succeeds and stores the tracking code on the order.

Reference docs: EasyPost docs, Stripe Checkout docs and Cloudflare Workers docs.
