What the API does

EndpointDirectionPurpose
Order dispatchShop-E-Business → your HTTPS endpointNew order, HS256 JWT (CustomOrderId, shop), 5-minute expiry
POST /api/exposure/order-statusYou → Shop-E-BusinessCustomOrderId, DeliveryStatus, DeliveryTrackingUrl, PaymentStatus
