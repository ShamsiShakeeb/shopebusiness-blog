Platform fee vs processing fee

A platform transaction fee is a percentage the store builder takes from each sale. A payment processing fee is what the card processor charges to move money. They are separate. Removing the platform fee does not remove processing fees, which are set by processors such as Stripe (see Stripe pricing).
