Short answer: Shop-E-Business connects to a courier API automatically through a Cloudflare Worker it generates for you. On Tier-2 ($18/year), the Worker holds your EasyPost key as a secret (COURIER_API_KEY), calls the EasyPost shipments endpoint for each paid Stripe order, and reports status back. Developers can swap or add courier APIs by editing the Worker.

The connection pieces

PieceValue
SecretCOURIER_API_KEY (EasyPost key)
VariableEASYPOST_SHIPMENT_URL = https://api.easypost.com/v2/shipments
Routesyourdomain.com/apiEndpoint, yourdomain.com/stripe-webhook
AuthShort-lived HS256 JWT from Shop-E-Business

API references: EasyPost Shipments API, Cloudflare Workers docs, Stripe webhooks docs.

Why a Worker?

Your keys never leave your Cloudflare account, the script contains no seller-specific values, and you can change courier logic without waiting for a platform update. See the Expose API and Cloudflare Worker guide.

Requirements

  • Tier-2 ($18/year) or Tier-1 plus the $8/year custom-domain add-on.
  • A verified custom domain with DNS on Cloudflare (proxied records, SSL Full (Strict)).
  • Your own Stripe account and EasyPost account with API keys.
  • Courier settings saved: sender name, ship-from address, parcel length/width/height (inches) and weight (ounces).
